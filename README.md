# Sistem Informasi Absensi

# Deskripsi
Website Administrator merupakan bagian dari Sistem Informasi Absensi Mahasiswa (SIA) yang digunakan untuk mengelola data akademik dan memantau aktivitas sistem. Halaman ini dirancang untuk memudahkan administrator dalam mengakses informasi mahasiswa, jadwal perkuliahan, dan rekap absensi.

# Fitur
- Dashboard: Menampilkan halaman utama administrator.
- Data Mahasiswa: Menampilkan informasi data mahasiswa.
- Data Jadwal: Menampilkan informasi jadwal perkuliahan.
- Rekap Absensi: Menampilkan rekap kehadiran mahasiswa.
- Tambah Mahasiswa: Menyediakan formulir untuk memasukkan data mahasiswa.

# Teknologi
- HTML5 untuk struktur halaman.
- CSS3 untuk desain dan tata letak.
- JavaScript untuk interaksi dan validasi formulir.
- Visual Studio Code sebagai editor kode.

# Cara Menjalankan
1. Buka folder Administrator di Visual Studio Code.
2. Buka file `index.html`.
3. Jalankan menggunakan Live Server atau browser.
4. Gunakan menu navigasi untuk mencoba fitur yang tersedia.

# Catatan
Website ini merupakan prototipe frontend untuk tugas UTS Pemrograman Web. Data yang ditampilkan merupakan data contoh dan belum terhubung dengan database.

# Kesimpulan
Website Administrator dirancang untuk memberikan kemudahan dalam mengakses dan mengelola informasi akademik melalui antarmuka yang sederhana dan terstruktur.
